Initial release of the effect-rdf family on Effect 4 (peer `effect` `>=4.0.0-rc.118`): the RDF 1.2 data model (`@thomasfosterau/effect-rdf`); N-Triples / N-Quads, Turtle / TriG, Notation3, JSON-LD 1.1, RDF/XML and RDF/JSON syntaxes; the SPARQL 1.1 / 1.2 engine with its SQL storage backend, Protocol server and client; and SHACL Core, SHACL-SPARQL and ShEx 2.1 validation. Each package README states its W3C conformance results.
